# T9 Handoff: Execution Layer

**Date:** 2026-08-12 (late evening)
**Built by:** Claude Code
**Task:** T9 execution layer + minimal T10 (botctl) + engine entrypoint

## What was built

- `engine/executor.py` - Executor: consumes the scanner's signal queue.
  Entries: stale-data check (SPEC 6.2) -> risk gate -> paper fill ->
  `mark_signal_acted`; blocked entries get their skip_reason written back to
  the signals row (the honest skipped-signal dataset, SPEC 9.3). Exits:
  close_long closes the pair's position; tighten_stop raises stops (up-only,
  SPEC 5.1 #5). Monitor tick: `PaperAdapter.check_exits()` (exchange-side
  stop/target simulation) + equity snapshots every 15 min (SPEC 7.1, feeds
  the ops backstops). HALT file honored every step (SPEC 6.3): closes all
  positions, blocks entries, stays halted across restarts.
- `engine/main.py` - entrypoint wiring collector -> scanner -> executor.
  REFUSES any mode except paper, regardless of config (SPEC 2: go-live
  criteria are prerequisites, not triggers).
- `botctl.py` - status / halt "reason" / resume --ack <id>. Halt writes the
  HALT file with an id; resume requires that id back.
- `tests/test_executor.py` - 8 tests: acted-flag protocol both directions,
  stale-data gate, close_long, tighten_stop up-only, halt behavior, monitor
  stop-trigger, snapshot writing.

## How to run (first supervised paper session)

```
python3 -m engine.main          # starts collector+scanner+executor, paper mode
python3 botctl.py status        # positions, equity, halt state
python3 botctl.py halt "test"   # kill switch drill - do this once early
python3 botctl.py resume --ack <id>
```

Recommendation: first run supervised for an hour during active market hours;
verify signals rows appear with acted=0, the risk gate logs its verdicts, and
an equity snapshot lands within 15 minutes.
