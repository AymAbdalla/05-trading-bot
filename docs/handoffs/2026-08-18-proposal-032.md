032-pm-longshot-fade-hold-to-resolution.md`) in full before writing tests.
Seven classes, matching the brief's seven items exactly:

1. `TestSigmaEstimation` - `WindowTapeByAsset.sigma_window_bps` against an
   independently-computed `statistics.stdev` of a synthetic 20-window move
   series; the <20-window `insufficient_window_history` skip.
2. `TestTRemMath` - `sigma_rem_bps` in `ENTER` features matches
   `sigma_window_bps * sqrt(t_rem / 900)`; a zero-variance tape (flat
   synthetic windows) produces `non_positive_sigma_rem`.

   p_tail=0.5; a spot solved by inverting the strategy's own formula for
   z=1.96 gives p_tail approx 0.025 (checked against `NormalDist(0,1).cdf`
   directly, not re-derived from the strategy's math).
4. `TestEntryGates` - the five ALL-required gates (t_rem band, favorite ask
   band, edge vs fair, tail-bid convergence, ask depth) each fail alone on
   its own named skip, isolated by holding every other gate passing.
5. `TestSizeCap` - `NOTIONAL_USDC == 10.0` and the resulting share count;
   same-window re-entry refused (`already_entered_this_window`); three
   distinct 15m markets at the same instant show ENTER, ENTER, then
   `strategy_concurrency_cap_reached` at `MAX_CONCURRENT_POSITIONS == 2`.
6. `TestExit` - `estimate()`'s final-third gating and `for_side` contract;
   `manage_exit` HOLDs when the thesis is intact, EXITs at
   `URGENT_SELL_LIMIT` (0.00) only when both the strike-crossing condition
   AND the 0.80 bid ceiling hold together, still HOLDs when only one of
   those two is true; every DATA_BLOCKER-shaped hold reason (`no_orderbook`,
   `no_bid_liquidity`, `no_live_spot_for_stop`,

   accepted for interface compatibility and never inspected - there is no
   time-based exit to test against).
7. `TestRegistry` - 23 strategies, this one at index 22, first 8 unchanged.

No deviations from the brief's test plan. One choice worth flagging: rather
than hand-picking "nice" numeric fixtures, gate-isolation tests solve for the

`d_adj = z * sigma_rem` formula (`_spot_for_z()`), then assert against an
independently-computed `p_tail` via `NormalDist.cdf`. That is solving for an
input given a desired output, not re-deriving the gate logic under test.
